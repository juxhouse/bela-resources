## Prepare your .NET Project (Other Build Tool)

Use this when your project is prepared by a build tool, build service, or restore process not covered by the standard .NET instructions.

This is the directory structure read by BELA:

- `.sln` or `.csproj` files for the projects you want to analyse.
- Source files referenced by those projects.
- `.bela/dependencies` containing restored NuGet packages for .NET Core projects.
- Restored package directories inside the project workspace for .NET Framework projects.

Make sure the `.bela` directory exists. The update file to be sent to BELA will be created in there:

`mkdir -p .bela`

The updater runs offline, so restored packages must already exist in the mounted workspace before analysis.

Your project is now ready to be [analysed by BELA](/updaters/.NET.md).
